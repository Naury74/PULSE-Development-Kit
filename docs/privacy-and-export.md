# 개인정보와 내보내기

## 저장 전 마스킹

- 헤더, URL, 실패 메시지는 수집 큐에 넣기 전에 마스킹하고, 본문은 저장 스레드에서 마스킹합니다. 저장소는 마스킹을 거친 기록 타입만 받습니다.
- 마스킹된 값은 `[REDACTED]`로 바뀌며, 원래 값은 어디에도 남지 않습니다. 원래 값을 보여 주는 기능도 없습니다.
- 마스킹할 수 없는 본문은 저장하지 않고 그 이유만 남깁니다.
- URL의 사용자 정보(`user:pass@`)와 fragment는 제거합니다. 경로에 들어 있는 비밀 값은 판별할 수 없어 그대로 둡니다.
- JSON 본문은 민감한 키의 값을 마스킹하고, 문자열 값도 검사합니다. 문자열이 JSON이면 두 단계까지 파싱해 같은 규칙을 적용하고, 그렇지 않으면 문자열 안의 URL 쿼리와 `name=value` 형태의 민감한 값을 마스킹합니다. 받은 요청을 그대로 돌려주는 서버의 응답에 대비하기 위해서입니다. 이런 형태가 아닌 자유 텍스트 속 비밀 값(예: `"비밀번호는 1234"`)은 찾아낼 수 없습니다.

## 함께 기록하는 컨텍스트

`ContextCapture`가 켜져 있으면(기본값) 요청마다 화면(Activity 이름), 포그라운드 여부, 네트워크 종류를 함께 저장합니다. 개인 식별 정보는 아니지만 사용 흐름이 드러나므로, 내보낸 파일을 공유할 때 이 점을 고려하세요. 끄려면 `ContextCapture.NONE`을 사용합니다.

## 앱 로그, 크래시, 화면 캡처

로그, 크래시 스택, 종료 이유 메시지도 저장하기 전에 같은 규칙(URL 쿼리, `name=value`, JSON 키)으로 마스킹합니다. 다만 로그 문장에 그대로 적힌 개인정보(이름, 전화번호 등)는 찾아낼 수 없습니다. `logcat`을 켜면 이 앱이 Logcat에 출력하는 모든 로그가 저장되므로, 개인정보를 로그로 남기는 라이브러리는 `logcatIgnoredTags`로 제외하세요.

화면 캡처(플로팅 버튼, `screenshotOnCrash`)는 화면에 보이는 그대로 저장되므로 마스킹되지 않습니다. 기본값은 꺼짐이며, 켰다면 내보내거나 공유하기 전에 내용을 확인하세요.

## 버그 보고

보고서의 텍스트는 저장하기 전에 마스킹하고, 화면 캡처는 편집 화면에서 마스킹한 영역의 픽셀을 덮어쓴 이미지만 저장합니다(편집 전 캡처는 메모리에만 둡니다). 앱이 캡처를 막아 둔 화면(`FLAG_SECURE`)과 `ScreenshotPolicy.blockedScreens`에 지정한 화면은 캡처하지 않습니다. 내보내거나 보내기 전에 개인정보 확인란을 체크해야 하며, 전송은 코드에서 설정한 허용 호스트로만 합니다. 자세한 내용은 [bug-reports.md](bug-reports.md)를 참고하세요.

## 로컬 데이터와 화면 구조

로컬 데이터 보기는 `DataInspection`으로 등록한 저장소만 읽기 전용으로 열고, 이름이 민감한 키나 열의 값과 텍스트 속 비밀 값을 마스킹합니다. 이름이 평범한 열에 든 개인정보(이름, 주소 등)는 마스킹하지 못하므로 `withSensitiveNames`로 추가하거나 아예 등록하지 마세요. 화면 구조 보기는 텍스트 내용을 담지 않고 길이만 담습니다.

## 원격 보고

`PulseConfig.remote`를 지정하거나 설정 탭에서 켠 경우에만 크래시, 오류 등을 마스킹된 상태 그대로 지정한 서버로 보냅니다. 인증 헤더는 PULSE 기록에 남지 않으며, 설정 탭에서 입력한 토큰은 이 앱 전용 저장소(SharedPreferences)에만 저장하고 다시 표시하지 않습니다. 자세한 내용은 [remote-reporting.md](remote-reporting.md)를 참고하세요.

## 저장 위치

데이터는 `noBackupFilesDir/pulse/`에 저장됩니다(Room DB `pulse.db`와 본문 파일 `bodies/`). 자동 백업이나 기기 이전 대상에 포함되지 않습니다. `clear()`를 호출하거나 설정 탭의 지우기로 모두 삭제할 수 있습니다.

## 화면

인스펙터 Activity는 `exported=false`입니다. debug 빌드의 런처 아이콘만 다른 앱(런처)에서 열 수 있으며, 화면을 띄울 뿐 데이터를 반환하지는 않습니다. 본문은 복사 버튼을 눌렀을 때만 복사되고, Android 13 이상에서는 클립보드 미리보기에 내용이 표시되지 않습니다.

알림에는 최근 요청의 메서드, 경로, 결과가 표시됩니다. 잠금 화면에서는 개수만 보이며, 알림을 끄려면 `pulse_notification_enabled`를 false로 설정합니다. 요청 공유는 사용자가 선택한 앱으로만 보내고, 마스킹을 거쳤더라도 개인정보가 남아 있을 수 있으니 공유하기 전에 확인하세요.

## 내보내기

트래픽 탭의 내보내기는 현재 검색 조건과 필터에 맞는 요청(최신순, 최대 10,000개)을 사용자가 선택한 위치(Storage Access Framework)에만 저장합니다. 자동으로 공유하거나 업로드하지 않습니다.

- **HAR 1.2**: 관찰하지 못한 타이밍은 `-1`로, 알 수 없는 전송 크기(`bodySize`, `headersSize`)도 `-1`로 기록합니다. PULSE 고유 정보는 `_pulse` 확장 필드에 들어 있습니다.
- **PULSE JSON**(`pulse.capture.v1`): 본문 상태, 마스킹 개수, 타이밍 단계를 모두 담습니다.
- 파일을 쓰기 직전에 현재 정책으로 **다시 마스킹**합니다. 다시 마스킹할 수 없는 본문은 제외하고, 제외한 개수를 알려 줍니다.
- 쓰기에 실패하거나 화면을 벗어나 취소되면 쓰다 만 파일을 삭제합니다.
- **cURL 복사**: 마스킹된 헤더는 넣지 않고 주석으로 알려 주며, 상태를 바꾸는 메서드에는 경고 주석을 붙입니다.

로그 탭의 내보내기는 텍스트, JSON(`pulse.events.v1`), CSV 중에서 형식을 고르고, 현재 조건에 맞는 로그나 전체 로그를 파일로 저장하거나 바로 공유합니다. 이때도 쓰기 직전에 다시 마스킹합니다.

마스킹을 거쳤더라도 파일에 개인정보가 남아 있을 수 있으니 공유하기 전에 확인하세요.
