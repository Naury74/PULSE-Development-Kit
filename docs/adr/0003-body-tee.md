# ADR-0003: 본문은 호스트가 주고받는 바이트만 복사(tee)

상태: 채택

## 배경

응답 본문은 스트리밍될 수 있고 한 번만 읽을 수 있다. 요청 본문은 one-shot이거나 duplex일 수 있다. SDK가 본문을 미리 읽거나 두 번 쓰면 호스트의 동작이 바뀐다.

## 결정

- 응답: 원래 `ResponseBody`를 감싼 `ForwardingSource`가 호스트가 `read`한 바이트만 상한까지 복사한다. EOF에서만 저장 후보로 넘기고, 끝까지 읽기 전에 닫으면 `INCOMPLETE_READ`로 둔다. 미리 읽거나 버퍼에 모으지 않는다.
- 요청: JSON이고 one-shot·duplex가 아닐 때만 `RequestBody`를 감싸, OkHttp가 네트워크로 쓰는 바이트를 복사한다. 본문을 따로 한 번 더 쓰지 않는다. 리다이렉트·재시도로 여러 번 쓰여도 처음 끝까지 쓴 결과만 쓴다.
- 상한을 넘으면 복사본을 버리고 바이트 수만 센다.
- HEAD·1xx·204·304와 길이 0 응답은 본문을 기다리지 않고 바로 완료로 기록한다.

## 결과

- 호스트가 본문을 읽지 않으면 본문은 기록되지 않는다.
- 요청 본문을 감싼 객체가 호스트 interceptor에 보이므로, JSON 본문에만 적용해 `FormBody`·`MultipartBody` 타입 검사를 깨지 않게 한다.
