# ADR-0002: 저장 전에 마스킹하고, 마스킹할 수 없으면 저장하지 않음

상태: 채택

## 결정

- 헤더, URL, 실패 메시지는 수집 큐에 넣기 전에 마스킹합니다. 이 작업은 네트워크 스레드에서 문자열 비교만으로 처리합니다.
- 본문은 원본 바이트를 큐에 넣고, 저장 스레드에서 JSON으로 파싱해 마스킹합니다. 파싱은 네트워크 스레드에서 하지 않습니다.
- 저장소가 받는 타입(`CaptureRecord`)은 생성자가 `pulse-core` 안에만 있으므로, 마스킹 단계를 거치지 않고는 만들 수 없습니다.
- JSON이 아닌 본문, 파싱이나 문자 디코딩에 실패한 본문, 64단계보다 깊게 중첩된 본문, 상한을 넘은 본문, 호스트 앱이 끝까지 읽지 않은 본문은 저장하지 않고 이유(`BodyState`)만 남깁니다.
- 원래 값을 보여 주는 기능은 제공하지 않습니다. 원래 값이 어디에도 남아 있지 않기 때문입니다.

## 결과

- 일부 진단 정보(형식이 깨진 본문, form 본문)는 의도적으로 포기합니다.
- 기본 규칙은 범위를 넓게 잡아 마스킹하므로, 비밀이 아닌 값도 마스킹될 수 있습니다.
